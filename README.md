# Day 35 – Linear Regression Model Evaluation

## Objective
To evaluate a Linear Regression model using Mean Absolute Error (MAE) and Mean Squared Error (MSE).

## Tools & Technologies
- Python
- Pandas
- Scikit-learn
- Jupyter Notebook

## Dataset
Salary vs Experience Dataset.

The dataset contains:
- Experience (Years)
- Salary

## Tasks Performed
1. Created a Salary vs Experience dataset.
2. Separated input features and target values.
3. Split the dataset into training and testing data.
4. Trained a Linear Regression model.
5. Predicted salaries using the trained model.
6. Compared actual and predicted salaries.
7. Calculated Mean Absolute Error (MAE).
8. Calculated Mean Squared Error (MSE).
9. Interpreted the model evaluation results.

## Evaluation Metrics

**Mean Absolute Error (MAE):**
Measures the average absolute difference between actual and predicted values.

**Mean Squared Error (MSE):**
Measures the average squared difference between actual and predicted values.

## Key Learnings
- Learned how to evaluate a Linear Regression model.
- Understood MAE and MSE.
- Compared actual and predicted values.
- Learned how to interpret prediction errors.

## Conclusion
Successfully evaluated a Linear Regression model using MAE and MSE and understood how these metrics help measure prediction errors.
